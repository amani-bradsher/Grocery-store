# Grocery-store
This is a program that I've written in Python and is a simple supermarket system. It lets the user pick items, choose how many they want, and adds everything to a cart. It also uses discounts for some items and calculates the total. At the end, it prints out a receipt with the final price.

## Built With
- Python
- Object-Oriented Programming
- User Input
- Conditional Statements
- Loops

## What I Learned
- How to create and use Python classes
- How inheritance works in object-oriented programming
- How to store cart items using lists
- How to calculate totals and discounts
- How to use loops and conditionals to create an interactive program
- How to organize code into reusable methods
